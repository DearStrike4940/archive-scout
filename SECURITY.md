# Security policy

Report security problems privately through GitHub's private vulnerability reporting feature when enabled. Do not include sensitive archived content, credentials, personal data, or exploit details in a public issue.

Archive Scout processes untrusted archived HTML as text. It does not execute downloaded scripts, open archived pages automatically, or render downloaded HTML in an embedded browser. Preserve those boundaries when contributing.

The community DMG is ad-hoc signed and is not Apple-notarized. Verify release checksums and download only from the repository's official Releases page.
